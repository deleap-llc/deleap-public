Website: https://apps.deleap.org/

New products can receive their own directory under `products/` and dedicated policies when their data practices have been reviewed.

## Publication status

The product directory is published. Support and deletion-request contact: sweet.kandy@gmail.com. The Kin Stream Deck Android privacy policy is published at kin-stream-deck/android-privacy/ with owner-approved manual privacy support and explicit billing-ledger retention disclosures. Other product policies remain pending; do not submit those placeholder pages as app-store policies.

Before policy publication, reconcile policies with deployed behavior, document verification and fulfillment including retention exceptions, and approve the effective policy text. Do not collect personal data through public issues.

## Updating the site

Edit static HTML and CSS on a branch, review the change, then merge to `main`. GitHub Pages publishes the repository root. No build dependencies or custom analytics are used. Hosting is provided by GitHub; this is not a statement about GitHub hosting logs.

Keep this repository limited to public documentation and approved branding. Never add application source, credentials, tester details, internal release reports or personal account data. Policies must be reviewed per product; adding a product does not imply it has the same data practices as Kin.

Preview locally with `python -m http.server 8000` from this folder.

Kandy Labs branding and icons are retained by their respective owners. No application-source license is granted by this documentation repository.
