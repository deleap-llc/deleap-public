KIN STREAM DECK · PUBLIC TEST

Install and connect

You need the Windows companion on your PC and the Android app on your phone.

Windows test release 0.2.0.3

Download the signed x64 MSIX from the product page. Node is bundled; no developer SDK is required. This test release has not yet completed end-to-end acceptance. Android testing requires an enrolled account.

1. Install the Windows companion

  1. On your Windows x64 PC, open the product download page in your browser and select the signed Windows MSIX download.
  2. Open the downloaded .msix file from your browser or Downloads folder. Windows App Installer should open.
  3. Check that the application is Kin Stream Deck and the publisher is DELEAP LLC. Choose Install or Update.
  4. Launch Kin Stream Deck from Start and use its window or notification-area icon to open the companion.

If Windows blocks installation or reports a different publisher, contact support with the message. Do not disable Windows security or install a test certificate. A valid signature does not guarantee that Windows will show no reputation warnings.

2. Install the Android test app

  1. Open the Google Play test enrollment page, signed in with a Google account already included in Kin internal testers. The test is limited to the first 100 eligible testers.
  2. Opt in to the test, then open the Google Play listing on your phone. It may show com.kandylabs.kinstreamdeck (unreviewed) and developer Sweet Kandy (DELEAP LLC).
  3. Choose Install or Update in Google Play, then open Kin Stream Deck.

If Play says you are not eligible or offers no update, check that you are using the account enrolled in the test and contact support.

3. Pair and try your deck

  1. Keep both devices on the same trusted local network, with the Windows companion running.
  2. Follow the pairing instructions displayed by the apps. Keep pairing codes and QR codes private.
  3. Wait for your deck to appear on the phone, then try a harmless action such as opening an application.
  4. Close and reopen the phone app to check that it reconnects. You can also quit and reopen the Windows companion to check that your setup persists.

If discovery or pairing fails, record the message and contact support. Keep your security settings enabled.

Something went wrong?

Contact sweet.kandy@gmail.com with the download page you used, both app versions, your operating system versions, and the step that failed. Remove personal information, pairing codes and QR codes from screenshots.
