Install or update

  1. If the companion is already running, quit it from its menu-bar menu. Keep your existing app support data and pairing.
  2. Download the ZIP above and open it in Finder to extract KinStreamDeck.app.
  3. Move the extracted app to Applications. For an upgrade, replace the existing KinStreamDeck app after quitting it.
  4. Open KinStreamDeck from Applications and complete the compact required setup.
  5. Keep your computer and phone on the same trusted local network, then open the phone app. Existing pairings should reconnect; a new phone pairs using the companion's current pairing screen.

This download is a ZIP, not a disk image. It does not use a disk-image drag-to-Applications window. Keep macOS security protections enabled. If macOS blocks the app, stop and contact support with the exact message rather than bypassing the warning.

Required Accessibility setup

The compact setup window verifies Accessibility access for the launcher and its bundled input helper before computer-control setup is complete. Follow its instructions if macOS requires access in System Settings > Privacy & Security > Accessibility, then return to the app to verify again. macOS controls permission grants; installing the app cannot silently grant them.

On the tested upgrade, existing launcher and helper permissions were recognized and the required setup completed without granting new access. A fresh installation can require your interaction. Once setup is complete, the large diagnostics view is not the default setup screen; open diagnostics explicitly when needed.

Other features can require separate permissions: Automation for controlling other apps, and Input Monitoring plus an explicit local confirmation for optional macro recording. Allow only the access needed for features you choose. No Screen Recording requirement has been established for these controls.

What has been checked

The published ZIP's checksum, app signatures, notarization ticket and macOS Gatekeeper assessment were verified. An in-place 0.2.1 to 0.2.3 upgrade preserved the tested computer's pairing, TLS identity, decks and configuration. The iPhone candidate reconnected without a new PIN, and a supervised delay-only action received a successful acknowledgement.

These observations do not establish every native keyboard/mouse effect, reboot scenario, fresh-machine permission flow or purchase flow. The ZIP update does not establish a disk-image installation flow. Phone release checks continue separately.

Pairing and support

Pairing uses an encrypted local connection with certificate verification and a revocable token. Keep PINs and QR codes private. For support, contact sweet.kandy@gmail.com with the Mac model, macOS version, app versions and the step that failed. Review logs and screenshots before sharing; never send passwords, pairing tokens, private deck contents or full network details.

Phone availability

The public iPhone TestFlight invitation remains separate from this Mac download. TestFlight shows current public beta availability and eligibility. A newer signed candidate has been tested locally but is not yet uploaded or released to the App Store. Requires iOS 17 or later and Apple's TestFlight app.

See the product page for phone test links and read the iOS privacy policy. Publishing Mac 0.2.3 does not publish the iPhone app.
