KIN STREAM DECK · MAC TESTING

Install the Mac beta

The Apple silicon Mac beta is signed with Developer ID and notarized by Apple. Download version 0.2.0 from our GitHub prerelease; iOS TestFlight availability is listed on the product page.

Before you download

Download Mac test 0.2.0 · Apple silicon. Check the release notes, verification and checksum. Keep macOS security protections enabled.

Four-day installation test

When the Mac installer and iOS TestFlight invitation are linked from the GitHub-hosted product page, we will announce a four-day test window and the exact versions. Begin there, download and install the Mac beta, pair your phone, and verify controls and reconnects. Final release follows a review of the test results.

A USB-installed development app does not complete this download-and-install check. Keep your existing app data and pairing; upgrades should preserve them. Report any unexpected reset.

Which Macs?

Current testing uses Apple silicon. Intel and universal builds have not been verified. The current build targets macOS 13 or later; operation on macOS 13 still needs validation. Final supported systems will be listed with the download.

Installation

  1. Use the Mac download linked from the product page.
  2. Open the disk image, drag KinStreamDeck into Applications, and eject the disk image.
  3. Open the app and use its four-dot ring menu and Setup & Diagnostics to follow pairing instructions.
  4. Keep the Mac and phone on the same trusted local network. Keep pairing PINs and QR codes private.

The Mac package includes its runtime; testers should not need Node.js, Homebrew, or Xcode. The final package will be checked on a clean Mac. If macOS blocks the app, stop and contact support with the exact message.

Permissions depend on the controls you use

  • Local Network access supports discovery and communication with the phone.
  • Keyboard and mouse controls can require Accessibility. Keyboard shortcuts and Music or Spotify playback can also require Automation access.
  • Optional macro recording requires Accessibility, Input Monitoring, and a separate local recording confirmation. Recording is visibly indicated and drafts require review.

Allow only the access needed for features you choose. We are still verifying the prompts and denial/retry behavior on the packaged app. No Screen Recording permission is established as a requirement for these controls.

Pairing, saved decks, and diagnostics

Pairing uses an encrypted local connection with certificate pinning. Shared host decks and reconnect behavior are undergoing acceptance testing. Native input effects, reboot and upgrade persistence, physical-phone compatibility, and billing have not completed acceptance.

Use safe diagnostics for support. Review full logs before sharing; they can contain pairing information and local-network addresses. Never send pairing PINs, QR codes, tokens, passwords, or private deck contents.

Phone testing

The existing Android internal-test instructions remain available. Mac compatibility is being checked separately. iPhone beta installation uses TestFlight. Version 1.0 (3) passed processing and is waiting for Apple’s external beta review; public installation becomes available after approval. Requires iOS 17 or later. A Simulator app or local development archive is not the tester download.
