KIN STREAM DECK · WINDOWS TEST COMPANION

Windows data handling

Kin Stream Deck is operated by DeLeap LLC. This page describes observed Windows companion behavior; it does not describe the Android app.

About this information

This Windows-specific summary combines the product's existing service privacy declarations with the companion's data-handling behavior. It does not replace the Android privacy policy.

On your PC

The companion stores settings, a generated installation identifier, decks, pairing tokens, and its TLS certificate and private key in %APPDATA%\KinStreamDeck. Certificate metadata includes the local host name. Treat this folder as private.

Local state is designed to persist. Do not assume uninstalling the companion removes it.

Connecting your devices

Local mDNS/Bonjour discovery advertises the service name, port and protocol information. The paired phone and Windows companion exchange capabilities, decks and action traffic over an encrypted local WebSocket connection. Network metadata is visible on the local network.

Optional shortcut learning

Shortcut learning is off by default and requires explicit consent. While enabled, it counts supported shortcut combinations in supported Windows apps. It stores local aggregate counts, app/action identifiers and meanings you confirm, plus your learning preferences. It does not retain general typing, raw key-event history, clipboard contents or window/document contents, and learning does not send data to an AI service.

Use the visible tray or app controls to pause or stop learning. You can exclude apps and delete learned history. Review the app, meaning and destination before adding a suggested button; existing custom decks are not rearranged. This test supports selected Notepad and Teams shortcuts on the US keyboard layout. Learned actions require the intended app already in the foreground.

When you request AI drafting

The companion sends your description and a limited set of capability information to its configured HTTPS gateway. The request includes the installation identifier and may include an operation trace identifier. Installed-application and scene lists are empty in this request, but action and plugin capabilities are included.

Requests travel over HTTPS and may be forwarded to the configured AI model provider to generate a response. The gateway is designed without a user database and does not intentionally persist request bodies or installation identifiers. Hosting infrastructure and the configured model provider may retain limited operational logs according to their own terms and retention settings.

The installation identifier supports abuse prevention and rate limiting and is not tied to a user account. AI-generated actions are drafts that you can review before saving or executing.

Telemetry and diagnostics

Custom telemetry is disabled by default, with no default export endpoint. Export requires both explicit enablement and a configured endpoint. The implementation limits exported events and properties rather than accepting arbitrary prompts, commands or credentials.

Diagnostic console output can contain pairing material and local identity paths. Do not share raw logs, pairing codes, QR codes, tokens or private keys. Remove sensitive information before sending a support report.

Service providers and advertising

We do not sell personal information or use app data for advertising. Information is disclosed to infrastructure and AI service providers as needed to provide requested AI functionality, protect the service and diagnose failures.

Privacy questions

Contact sweet.kandy@gmail.com and identify Kin Stream Deck and the platform you use. The AI gateway has no user account profile to delete. Provider operational logs remain subject to the provider's own terms and retention settings; local Windows state may persist after uninstall.
